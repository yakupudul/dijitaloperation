# MOXDOP Data Integrity Registry V1

Machine-readable integrity profiles for production datasets.

- JSON: `MOXDOP_DATA_INTEGRITY_REGISTRY_V1.json`
- Schema: `MOXDOP_DATA_INTEGRITY_REGISTRY_V1.schema.json`
- Implementation: `docs/implementation/DATA_POOL_INTEGRITY_RECONCILIATION.md`

This registry **references** Data Contract Dataset IDs and Storage Contract physical mappings. It does not redefine formulas, request fields, or datasets.
