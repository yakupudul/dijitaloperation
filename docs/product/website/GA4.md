# GA4 Connection

## Purpose

Website davranış/pazarlama kanıtı için Website Connection.

## User value

Traffic, landing, engagement, conversion sinyalleri teşhis ve önceliklendirmeyi güçlendirir.

## Core concepts

Capabilities: traffic, acquisition/channels, landing pages, engagement, conversions/key events, form/WhatsApp events where configured, page behavior, changes over time.

## MVP behavior

Looker-benzeri her metrik yok. Event adları müşteriye göre mapping/config gerektirebilir; varsayma.

## Important data / attributes

Property mapping, event mappings, evidence aggregates.

## Relationships

Website → GA4 connection → evidence/findings.

## Main screens / workflows

Connect + map events; collect; findings.

## Rules / invariants

Read-only. No GA4 write. No invented events.

## Derived information

Traffic/conversion change findings from compared periods.

## Later enhancements

Funnel diagnosis packs.

## Explicit non-goals

Full BI tool.

## Acceptance intent

GA4, website state + actionable findings için kanıt sağlar.
