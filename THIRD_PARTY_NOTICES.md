This project includes UI code adapted from the following third-party open-source projects.

## TailAdmin Laravel

The MoxDOP operator app (site-root TailAdmin shell) — its Blade layouts (`resources/views/operator/layouts/*`),
UI components (`resources/views/components/ta/*`), theme CSS (`resources/css/operator.css`),
and front-end bootstrap (`resources/js/operator.js`) — is adapted from **TailAdmin Laravel**,
a free Tailwind CSS admin dashboard template.

- Repository: https://github.com/TailAdmin/tailadmin-laravel
- License: MIT License
- Copyright: Copyright (c) 2025 TailAdmin

The TailAdmin blue `brand` color scale was replaced with the MoxDOP orange scale
(`brand-600 = #ea580c`). Spacing, gray tokens, dark-mode variants, `menu-item` utility
classes, card radii, and ApexCharts styling are retained from TailAdmin.
